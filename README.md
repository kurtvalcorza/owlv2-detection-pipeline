# OWLv2 base/16 ensemble open-vocabulary detection pipeline

DIMER inference and bounded-adaptation wrapper for **OWLv2** (`google/owlv2-base-patch16-ensemble`), Google Research's open-vocabulary detector — a CLIP ViT-B/16 image tower whose 3,600 patch tokens each propose a box scored against caller-supplied text queries — pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. The pipeline takes images and phrases, returns pixel-space boxes under a caller-owned threshold, and can fine-tune only the class and box heads on validated labelled-box records while the CLIP towers remain frozen.

## Upstream alignment

- Model: `google/owlv2-base-patch16-ensemble`
- Revision: `cfd3195ba4ea9592eec887ded089f4c08eff231d`
- Upstream weight license: Apache-2.0
- Upstream task: zero-shot (text-conditioned) object detection
- Repository adaptation: bounded class-head and box-head fine-tuning with Hungarian-matched focal + L1 + GIoU loss; image/text towers frozen; SafeTensors adapter export and verified fresh-base reload

## Quick start

```python
from PIL import Image
from owlv2_detection_pipeline import Owlv2DetectionPipeline

pipe = Owlv2DetectionPipeline.from_pretrained()          # stages + verifies weights/owlv2-base-patch16-ensemble first
result = pipe.detect(Image.open("street.jpg"), ["a photo of a stop sign", "a photo of a traffic light"])
for det in result["detections"]:                         # sorted by score, boxes are [x0, y0, x1, y1] pixels
    print(det["label"], det["box"], round(det["score"], 3))

# the threshold is the README example's value; override per call
result = pipe.detect(Image.open("street.jpg"), ["a photo of a cat"], threshold=0.3)
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed). On a fresh clone the manifest is committed but the weights are not: `Owlv2DetectionPipeline.from_pretrained(allow_download=True)` fetches exactly the missing manifest-listed files at the pinned revision, then verifies them.

## Weights layout

```
weights/owlv2-base-patch16-ensemble/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + SHA-256 (9 files)
  config.json                # Owlv2ForObjectDetection: 960px image, 16px patches, projection 512
  preprocessor_config.json   # pad to square (grey), resize 960x960, CLIP mean/std
  merges.txt  vocab.json  tokenizer_config.json  special_tokens_map.json  added_tokens.json   # CLIP BPE, 16 tokens
  model.safetensors          # git-ignored, 619,918,824 bytes
  README.md
```

`pytorch_model.bin` exists upstream and is deliberately not listed (pickle; DIMER does not accept `.bin`).

## Input ceilings and threshold

`MIN_IMAGE_SIDE = 16`, `MAX_IMAGE_SIDE = 4096`; `MAX_PROMPTS = 16` distinct phrases of at most `MAX_PROMPT_CHARS = 48` characters, each tokenised to at most `MAX_TEXT_TOKENS = 16` CLIP tokens (longer phrases are truncated by the tokenizer); `MAX_DETECTIONS = 3600` (one candidate per image patch); `DETECTION_THRESHOLD = 0.1` (the pinned README example's value). `detect` handles one image and `detect_batch` applies one phrase vocabulary to a bounded image sequence; the processor pads every image to a square and resizes it to 960×960. See `MODEL_CARD.md` for threshold ownership, score semantics, the absence of NMS, historical inference timing, and the recorded E2E Kaggle T4 run.

## Tutorials

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/owlv2-detection-pipeline/blob/main/tutorials/owlv2_detection_colab.ipynb)

`tutorials/owlv2_detection_colab.ipynb` is declared `E2E` / `GUIDED` under DIMER Notebook Specification 2.0 and is **standalone** (§4): generated by `tools/build_notebook.py`, it carries `pipeline.py`, `metrics.py`, and `samples.py`, plus the model identity, manifest digests, and runtime pins. Its default `Run all` path stages and verifies the pinned snapshot and a digest-pinned Public-Domain BCCD sample; validates and image-disjointly splits labelled `(image, phrases, boxes)` records; exercises the drawn-scene inference contract; scores empty, grid-prior, and frozen-model baselines; fine-tunes the class and box heads with validation-based epoch selection; evaluates the held-out split; exports a SafeTensors adapter; and reloads it into a fresh base for detection parity. BYOD accepts a zip or directory of images plus `boxes.csv` and is gated off by default. See `tutorials/README.md` for the full contract and `docs/release-verification.md` for the exact-blob runtime gate.
